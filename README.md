# Verilog RAM Design and Verification

## Project Overview
This project implements and verifies two RAM designs using Verilog HDL.

## 1. Single Port SRAM
- Single clock
- One address bus
- Read and write operations
- Synchronous read and write

## 2. Dual Port RAM
- Two independent ports
- Port A for writing
- Port B for reading
- Simultaneous read and write

## Technologies Used
- Verilog HDL
- Digital Electronics
- RAM Design
- Testbench Verification

## Project Files
- sram_single_port.v
- tb_sram_single_port.v
- dpram.v
- tb_dpram.v
